# MEA electricity payment data

ข้อมูลบิลและการชำระค่าไฟอยู่ใน PostgreSQL collector ที่ `stash.mea_electric` โดยเลือกบ้านด้วย `MEA_HOUSE_CA`

- `paid` เป็นยอดค่าไฟของรอบบิลเดิมที่หน้าเว็บใช้คำนวณการประหยัด ไม่ใช่หลักฐานการชำระ
- `payment_status` เป็นสถานะจากข้อมูลการชำระ; ค่าที่พบปัจจุบันคือ `paid`
- `payment_amount` เป็นยอดชำระจริง, `paid_at` เป็นวันที่ชำระ, `payment_channel` เป็นช่องทางชำระ
- หนึ่งธุรกรรมอาจชำระหลายบิลพร้อมกัน และ `payment_amount` เดียวกันจะถูกแนบซ้ำในทุกแถวที่ครอบคลุม ต้องจัดกลุ่มด้วย `receipt_no` (หรือวันที่ + ยอด + ช่องทางเมื่อไม่มีเลขใบเสร็จ) และแสดงยอดธุรกรรมเพียงครั้งเดียว ห้ามรวม `payment_amount` ตรง ๆ ต่อแถว
- `due_date` และ `outstanding_amount` รองรับบิลรอชำระหรือค้างชำระเมื่อ collector ส่งค่ามา
- บิลที่จับคู่ payment history ไม่ได้และมี `payment_status IS NULL` ต้องแสดงว่า “ยังไม่พบหลักฐานชำระ” และห้ามยืนยันว่า “ค้างชำระ” จนกว่าจะมีสถานะบิลปัจจุบันหรือยอดคงค้างจาก MEA

ดัชนี `pk_mea_electric (ca, month)` รองรับการดึงประวัติรายเดือนของบ้าน และ `ix_mea_electric_bill_no_normalized (ca, bill_no_normalized)` รองรับการจับคู่บิลกับข้อมูลการชำระ
